# Arthur: By Design — Visual Continuity Blueprint
## Core rule: one Arthur, three chapters
Arthur is one recurring character. Never generate a chapter-specific replacement face. Use the same approved reference imagery or artwork grounded in that reference. Check face, hair, build, age cues, skin tone, and any recurring companion before approving new scenes. Clothing, setting and expression may change. Current artwork reused by the chapter bridge: `arthur-leave-well.png`, `arthur-recover-well.png`, `arthur-live-well.png`. This reuse is **not** itself proof that all three source images depict an identical face; a visual identity audit remains necessary.

## Common screen grammar
- **Hero:** recognizable Arthur photo, brief emotional objective, one action.
- **Investment family:** bold visual cue, one sentence describing its purpose, visible capital/change; tap to explore.
- **Design A/B/C:** family visual cue plus large A/B/C identifier, single differentiator, optional details; paged on phones.
- **Strengthen / Extend:** reinforce-one vs broaden-two illustration; costs and dependency visible.
- **Disruption:** event visual first, plain-language change, what Arthur must accomplish.
- **Outcome:** Arthur image, clear result and immediate implication, inherited contribution only when actually demonstrated.
- **Three Futures:** three distinct visual cues, selected future emphasized; no generalized community readiness claims.
- **Transition:** three chapter thumbnails from actual existing assets, starting foundations, unresolved gaps.

## Visual acceptance requirements
1. **Identity audit:** visually compare approved reference and each source image; reject any image showing a different Arthur. Audit recurring family members too. No uncontrolled independent AI generation.
2. **Phone-first:** test 375px and 390px; no horizontal overflow; one dominant idea and image per screen; avoid a text wall.
3. **Comprehension:** image should make the change understandable before reading the full paragraph; decorative art alone is insufficient.
4. **Accessibility:** concise alt text conveys scene meaning, icons paired with visible words, meaning never color-only, tap targets at least 44px.
5. **Causality:** no visual should imply care capacity, clinical approval, accessible travel or staff that game facts did not establish.
6. **Facilitation:** outcomes, dependencies and discussion prompts fit the room display without needing a second operator.
